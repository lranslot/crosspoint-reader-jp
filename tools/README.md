# tools/

母艦 (PC) 側で動かす補助スクリプト。ファームウェアのビルドには関与しない。

## aozora2epub.py

青空文庫形式のテキストを、ruby 付き EPUB 3.0 に変換する。

```
python tools/aozora2epub.py 最終戦争論.txt 最終戦争論.epub
```

Python 3.6 以上、標準ライブラリのみ。入力の文字コード (Shift-JIS / CP932 /
UTF-8) は自動判別する。

**なぜ要るのか**: TXT リーダーは青空文庫記法を*除去*するので (F-8 段階1)、
`真面目《しんめんぼく》` の読みは捨てられる。EPUB に変換すれば読みが残り、
EPUB リーダーがルビを描く。端末側でルビを出せるようになる (F-8 段階2) までの
実用解。

**見出し注記**: 青空文庫は見出し注記を本文と同じ行にも、次の行にも書く。
どちらの書式も `<h1>`〜`<h3>` にする。

```
［＃５字下げ］第一章［＃「第一章」は大見出し］     ← インライン形式
第一章
［＃「第一章」は大見出し］                        ← 別行形式
```

別行形式では、注記が引用している文字列が直前の行と一致したときだけ見出しにする。
一致しないものは別の箇所を指している可能性があるので、本文のまま残す。
