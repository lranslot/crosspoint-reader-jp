## 再開の手順

```powershell
$env:PYTHONUTF8 = "1"

cd D:\dev\crosspoint-reader-jp
git fetch upstream --prune
git status
git log --oneline -5
git log --oneline 81028d58..upstream/develop    # 上流の進み具合（追随はしない）
```

**ビルド前に `$env:PYTHONUTF8 = "1"` が必須。**

**`.md` は読み物ではなく TODO の道具。**組版まわりの機能 (縦書き・ルビ・
禁則・傍点) は `.md` に適用しない。チェックボックスは `.md` のみ
(仕様書 §6.3「`.md` の位置づけ」)。

**端末で読む前提の文書 (`docs-jp/tests/` 配下) では、表・コードフェンス・
見出し記法を使わない。箇条書きの `- [ ]` は絶対に書かない。**
リーダーが解釈する Markdown は**チェックボックスだけ**で、他は生のまま出る。
`- [ ]` と書くと端末では本物のチェックボックスになる (仕様書 §6.3 / §8.7-10)。

**実機の見た目を確かめるときは写真ではなくスクリーンショット。**
POWER + DOWN で全画面から撮れる（設定画面でも可）。`/screenshots/` に
480×800 / 1bpp の BMP が出るので、PNG にして 1 px 単位で見る:

```powershell
python scripts/bmp_to_png.py G:/screenshots <出力先>
```


### 実機の作法

- **USB がロックされているので、書き込みは SD カード経由のみ。**
  `firmware.bin` を SD ルートに `update.bin` としてコピー → 起動 → **後で削除**
- **`settings.json` と `wifi.json` は絶対に消さない**
- **シリアル出力が無い。**診断は SD のファイルか画面に出す
- OTA と SD カード更新の機能を削除してはならない
