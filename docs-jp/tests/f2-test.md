# F-2 動作確認用ファイル

このファイルは Xteink X4 の実機で F-2 (チェックボックスのトグル) を
確認するためのものです。SD カードのルートか、書籍を置いているフォルダに
入れてください。UTF-8 (BOM なし) で保存されています。

各節に「期待される結果」を書いてあるので、端末の画面を見ながら確認できます。

---

## 節1: 基本形

ここは先頭ページです。下の最初の項目の箱が**反転 (黒地に白枠)** で
示されているはずです。

- [ ] 未チェックの項目 1
- [ ] 未チェックの項目 2
- [x] 最初からチェック済みの項目
- [ ] 未チェックの項目 3

期待: 電源短押しで反転している行がトグルする。側面ボタンで反転が上下に動く。

## 節6: 折り返し境界の確認

> **⚠️ A8 (2026-10-26) 以降、6-a と 6-c は自動的に合格します。**
> `- [ ] ` の前置きを**表示しなくなった**ため、`[ ]` / `[x]` / `[X]` の
> 字幅の違いが本文の位置に影響しなくなりました。
> **6-b と 6-d は引き続き有効です** — 「トグルで折り返しが動かない」ことは
> いまも満たされていなければならない要件です。

### 6-a. 目視での桁揃えテスト (シリアルが読めなくてもできる)

下の2行は、角括弧の中身以外はまったく同じ文字列です。

- [ ] ||||||||||||||||||||
- [x] ||||||||||||||||||||

**縦線が上下でぴったり揃っていれば、`[ ]` と `[x]` の幅は同じです。**
その場合、折り返しがトグルで変わる心配はありません。この節の残りは読み飛ばして構いません。

**ずれていれば幅が違います。**その場合だけ 6-b を確認してください。
ずれ幅は1文字未満のはずなので、画面に顔を近づけて見てください。

参考までに、下は上の2行をトグルして反転させたときの比較用です。
上の2行をトグルして `- [x]` / `- [ ]` にすると、縦線の位置が入れ替わるかどうかで
同じことが確認できます。

### 6-b. 折り返し位置の確認

長さを1文字ずつ変えた項目を並べてあります。トグルする前と後で、
折り返しの位置が変わる行が無いかを見てください。

- [ ] あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよ
- [ ] あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよら
- [ ] あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよらり
- [ ] あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよらりる
- [ ] あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよらりるれ
- [ ] あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよらりるれろ

期待: どの行もトグルの前後で折り返し位置が変わらない。
変わった場合は、その行だけ次のページとの間で文字が欠ける可能性がある。

### 6-c. 大文字 `[X]` の確認

下は 6-b と**まったく同じ長さ**の項目を、大文字の `[X]` で書いたものです。
`X` は `x` より幅が広いため、ここが揃っていないと
「一度トグルしただけで折り返しが変わる」ことになります。

- [X] あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよ
- [X] あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよら
- [X] あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよらり
- [X] あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよらりる
- [X] あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよらりるれ
- [X] あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよらりるれろ

期待: 6-b と 6-c で、同じ長さの行の**折り返し位置が一致している。**
また、これらをトグルして `- [ ]` にしても折り返しが動かない。

> **A8 以前は、未トグルの `[X]` 行だけ右端が数px はみ出していました。**
> 前置きを描かなくなったので、この症状は出なくなっているはずです。
> まだ出ていれば不具合です。

### 6-d. 【本命】1行に収まるかどうかの境目

**6-b / 6-c は必ず折り返すので、実は検証になっていません。**
`- [ ]` が単独で1行を占めるため、本文の折り返しはマーク幅と無関係になるからです。

問題が起きるのは、**項目全体が1行に収まるかどうかの境目**にあるときだけです。
下は1文字ずつ長くした短い項目を、`[ ]` と `[X]` で2組並べたものです。

- [ ] あいうえおかきくけこさし
- [ ] あいうえおかきくけこさしす
- [ ] あいうえおかきくけこさしすせ
- [ ] あいうえおかきくけこさしすせそ
- [ ] あいうえおかきくけこさしすせそた
- [ ] あいうえおかきくけこさしすせそたち
- [ ] あいうえおかきくけこさしすせそたちつ
- [ ] あいうえおかきくけこさしすせそたちつて
- [ ] あいうえおかきくけこさしすせそたちつてと
- [ ] あいうえおかきくけこさしすせそたちつてとな
- [ ] あいうえおかきくけこさしすせそたちつてとなに
- [ ] あいうえおかきくけこさしすせそたちつてとなにぬ

- [X] あいうえおかきくけこさし
- [X] あいうえおかきくけこさしす
- [X] あいうえおかきくけこさしすせ
- [X] あいうえおかきくけこさしすせそ
- [X] あいうえおかきくけこさしすせそた
- [X] あいうえおかきくけこさしすせそたち
- [X] あいうえおかきくけこさしすせそたちつ
- [X] あいうえおかきくけこさしすせそたちつて
- [X] あいうえおかきくけこさしすせそたちつてと
- [X] あいうえおかきくけこさしすせそたちつてとな
- [X] あいうえおかきくけこさしすせそたちつてとなに
- [X] あいうえおかきくけこさしすせそたちつてとなにぬ

**見るのは1点だけです。**
上の組と下の組で、**「2行に折り返し始める項目の位置が同じか」。**

同じなら、`[ ]` と `[X]` が同じ幅として測られている = 修正5 が効いています。
ずれていれば効いていません。

さらに、**折り返し始める直前の項目をトグルしてみてください。**
1行のままなら成功です。2行に変わったら、その行の下のテキストが
1行分どこにも表示されなくなっている可能性があります。

## 節8: チェックボックスが無いページ

ここから先はしばらく本文だけが続きます。側面ボタンは通常のページ送りとして
動作するはずです。箱はどこにも表示されません。

書籍端末で文章を読むという行為は、紙の本を読むこととは少し違う体験になります。
画面の書き換えに時間がかかること、指で押す場所が決まっていること、
明かりの下でしか読めないこと。制約はいくつもあります。

それでも電子ペーパーの端末を選ぶ理由があるとすれば、
何百冊もの本を持ち歩けることと、目が疲れにくいことでしょう。
液晶画面の光を長時間見続けるのとは、疲れ方が明らかに違います。

この端末は中国の小さなメーカーが作ったもので、
出荷時のファームウェアは中国語と英語にしか対応していません。
有志が作ったカスタムファームウェアを導入することで、
表示や操作を自分の好みに合わせられるようになります。

ただし、その導入経路は個体によって異なります。
USB 経由での書き込みが工場出荷時に無効化されている個体では、
SD カードを使った書き込みだけが唯一の手段になります。

この制約は不便に見えますが、悪いことばかりでもありません。
SD カード経由の手順は、USB がロックされているかどうかに関わらず同じように使えます。
つまり、手順書を分岐させる必要がないということです。

日本語を表示するためには、日本語の字形を含むフォントが必要になります。
組み込みのフォントには漢字も仮名も入っていないため、
別途フォントを用意して SD カードに置く必要がありました。

この点も、フォントを本体に焼き込むことで解決できます。
利用者がフォントを用意しなくても、最初から日本語で使える状態になります。

さて、そろそろ本文が終わります。次の節にはチェックボックスが戻ってきます。

期待: ここまでのページで側面ボタンが通常のページ送りとして動くこと。
箱が画面のどこにも出ないこと。**左の欄が空いたままにならず、本文が
左端から始まること** (`.md` でも箱が無い行は欄だけ空いて見えるのが正しい)。

## 節11: 【A8】箱の4状態を1画面で見る

**この節だけでスクリーンショット1枚になるように短くしてあります。**

- [ ] 未チェック 1
- [x] チェック済み 1
- [ ] 未チェック 2
- [X] チェック済み 2 (大文字)

**見るのは4点です。**

| # | 何を見るか | 合格の条件 |
|---|---|---|
| 1 | **箱の形** | 4行すべて同じ大きさ・同じ位置・同じ太さ |
| 2 | **チェックの有無** | 2行目と4行目だけにチェックが入っている |
| 3 | **選択の表現** | 反転しているのは**欄の背景だけ**。箱が塗りつぶされてはいない |
| 4 | **大文字 `[X]`** | 2行目 (`[x]`) と4行目 (`[X]`) の見た目が同一 |

**反転を上下に動かして4状態すべてを見てください。**
① 未選択・未チェック / ② 未選択・チェック済 / ③ 選択中・未チェック /
④ 選択中・チェック済 の4通りが、**箱の形を変えずに**区別できていれば合格です。

**不合格の例**: 選択中の箱が黒く塗りつぶされている
(= 「選択」と「チェック済み」が見分けられない。設計の主眼はここです)。

## 節12: 【最重要】書き戻しが正しいバイトに届くか

**この節だけで独立した手順になっています。**前回、焼く前後でファイルの状態が
食い違って原因を切り分けられませんでした。**今回は曖昧さが出ないように
作ってあります。**

下の 5 項目には `WB-01` 〜 `WB-05` という**重複しない目印**が付いています。
画面でも PC でも、どれがどれか取り違えようがありません。

- [ ] WB-01 これは最後まで未チェックのまま
- [ ] WB-02 これは最後まで未チェックのまま
- [ ] WB-03 ★この項目だけをトグルする★
- [ ] WB-04 これは最後まで未チェックのまま
- [x] WB-05 これは最初からチェック済みで、最後までチェック済みのまま

### 手順

**1. SD にまっさらな版を置く (PC で)**

リポジトリ側の版を SD に上書きコピーします。**開始状態を既知にするためです。**

```powershell
Copy-Item D:\dev\crosspoint-reader-jp\docs-jp\tests\f2-test.md G:\book\f2-test.md -Force
```

> **どちらがどちらか**
> | | パス | 端末が書くか |
> |---|---|---|
> | **SD 側 (検証対象)** | **`G:\book\f2-test.md`** | **書く** |
> | リポジトリ側 (原本) | `D:\dev\crosspoint-reader-jp\docs-jp\tests\f2-test.md` | **書かない** |
>
> **端末が触るのは SD 側だけです。**リポジトリ側が変わっていたら、
> それは端末ではない別の原因です。

**2. SD を取り外して端末に挿し、電源を入れる**

**3. `f2-test.md` を開き、この節 (節12) まで送る**

**4. `WB-03` の行にカーソル (反転) を合わせる**

側面ボタンで反転を上下に動かします。**`WB-03` の行が反転していることを
画面で確認してから次に進んでください。**

**5. 電源ボタンを短押しする。これ 1 回だけです**

`WB-03` の箱に x 印が付くはずです。**他の項目は触らないでください。**
2 回押すと元に戻ってしまい、何も確かめられません。

**6. 別のページへ送ってから、ホームに戻って端末の電源を切る**

進捗の保存を確実に走らせるためです。

**7. SD を PC に挿し、結果を確認する**

```powershell
Select-String -Path G:\book\f2-test.md -Pattern '^- \[.\] WB-0'
```

> **`^- \[.\] ` のアンカーは必須です。**これを外すと、この手順書の本文に出てくる
> `WB-03` という文字列まで拾ってしまい、どれが実際の項目か分からなくなります。

### 合格の条件

**出力は 5 行。角括弧の中が下のとおりであること。**

| 行 | 角括弧の中 | 本文 |
|---|---|---|
| 1 | 空白 | `WB-01 これは最後まで未チェックのまま` |
| 2 | 空白 | `WB-02 これは最後まで未チェックのまま` |
| **3** | **`x`** | `WB-03 ★この項目だけをトグルする★` |
| 4 | 空白 | `WB-04 これは最後まで未チェックのまま` |
| 5 | `x` | `WB-05 これは最初からチェック済みで、最後までチェック済みのまま` |

> **⚠️ この表を箇条書きの見本に戻さないこと。**
> **この手順書は端末でも開かれる。**`- [x]` と書いた行は、それがどんなつもりで
> 書かれていても**端末では本物のチェックボックスとして表示される。**
> 期待される出力を箇条書きで貼ると、**節12 の項目が 5 個から 10 個に増え、
> カーソルが見本の方に止まれる。**手順の一意性が壊れる。

| 見るところ | 合格 | 不合格だった場合に分かること |
|---|---|---|
| `WB-03` | **`[ ]` → `[x]`** | ここが変わっていなければ、書き込み自体が届いていない |
| `WB-01` / `WB-02` / `WB-04` | **`[ ]` のまま** | どれかが変わっていれば、**オフセットがずれている** |
| `WB-05` | **`[x]` のまま** | 変わっていれば、関係ない行に書いている |
| 行の文字 | **`WB-` の後ろの数字と本文が無傷** | 壊れていれば、書き込み位置が角括弧の中ではない |

**どれか 1 つでも外れたら、そこで止めて報告してください。**
ずれた項目の番号 (`WB-01` が変わった等) が、そのまま原因の手がかりになります。

### 続けて: 戻せるか

合格したら、**同じ `WB-03` をもう一度トグル**して手順 6〜7 を繰り返します。

**合格の条件**: `WB-03` が `- [ ]` に戻り、他の 4 行は変わらない。

### 続けて: 大文字の `[X]`

節2 の `- [X] 大文字の X` を 1 回だけトグルします。

```powershell
Select-String -Path G:\book\f2-test.md -Pattern '大文字の X'
```

**合格の条件**: `- [ ] 大文字の X (チェック済みとして扱われる)` になっている
(`[X]` → `[ ]`)。
