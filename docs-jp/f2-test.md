# F-2 動作確認用ファイル

このファイルは Xteink X4 の実機で F-2 (チェックボックスのトグル) を
確認するためのものです。SD カードのルートか、書籍を置いているフォルダに
入れてください。UTF-8 (BOM なし) で保存されています。

各節に「期待される結果」を書いてあるので、端末の画面を見ながら確認できます。

---

## 節1: 基本形

ここは先頭ページです。カーソル (`>`) は下の最初の項目に付いているはずです。

- [ ] 未チェックの項目 1
- [ ] 未チェックの項目 2
- [x] 最初からチェック済みの項目
- [ ] 未チェックの項目 3

期待: 電源短押しで `>` の付いた行がトグルする。側面ボタンで `>` が上下に動く。

---

## 節2: 記法のゆれ

- [ ] ハイフン
* [ ] アスタリスク
+ [ ] プラス
- [X] 大文字の X (チェック済みとして扱われる)

期待: 4つとも検出される。トグルしても行頭の記号 (`-` `*` `+`) は壊れない。

---

## 節3: インデント

- [ ] 親の項目
  - [ ] 半角スペース2つ
    - [ ] 半角スペース4つ
	- [ ] タブ1つ

期待: 4つとも検出される。トグルしてもインデントの深さは変わらない。

---

## 節4: 検出されてはいけないもの

以下は**チェックボックスとして扱われてはいけません。**
カーソルがこれらの行に止まったら不具合です。

-[ ] ハイフンの後にスペースが無い
- [] 角括弧の中が空
- [y] 中身が x でも空白でもない
[ ] 行頭に箇条書き記号が無い
文中に - [ ] が出てくるだけの行 (行頭が箇条書きではない)

期待: 上の5行はすべて素通りされ、カーソルが止まらない。

---

## 節5: 折り返す長い行

- [ ] この項目はとても長い文章になっていて、画面の横幅に収まりきらないので必ず折り返されるはずです。日本語には単語の区切りが無いため、文字単位で折り返されることになります。

期待: `>` は折り返された**1行目にだけ**付く。2行目以降には付かない。

---

## 節6: 折り返し境界の確認

### 6-a. 目視での桁揃えテスト (シリアルが読めなくてもできる)

下の2行は、角括弧の中身以外はまったく同じ文字列です。

- [ ] ||||||||||||||||||||
- [x] ||||||||||||||||||||

**縦線が上下でぴったり揃っていれば、`[ ]` と `[x]` の幅は同じです。**
その場合、折り返しがトグルで変わる心配はありません。この節の残りは読み飛ばして構いません。

**ずれていれば幅が違います。**その場合だけ 6-b を確認してください。
ずれ幅は1文字未満のはずなので、画面に顔を近づけて見てください。

参考までに、下は上の2行をトグルして反転させたときの比較用です。
上の2行をトグルして `- [x]` / `- [ ]` にすると、縦線の位置が入れ替わるかどうかで
同じことが確認できます。

### 6-b. 折り返し位置の確認

長さを1文字ずつ変えた項目を並べてあります。トグルする前と後で、
折り返しの位置が変わる行が無いかを見てください。

- [ ] あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよ
- [ ] あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよら
- [ ] あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよらり
- [ ] あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよらりる
- [ ] あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよらりるれ
- [ ] あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよらりるれろ

期待: どの行もトグルの前後で折り返し位置が変わらない。
変わった場合は、その行だけ次のページとの間で文字が欠ける可能性がある。

### 6-c. 大文字 `[X]` の確認

下は 6-b と**まったく同じ長さ**の項目を、大文字の `[X]` で書いたものです。
`X` は `x` より幅が広いため、ここが揃っていないと
「一度トグルしただけで折り返しが変わる」ことになります。

- [X] あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよ
- [X] あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよら
- [X] あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよらり
- [X] あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよらりる
- [X] あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよらりるれ
- [X] あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよらりるれろ

期待: 6-b と 6-c で、同じ長さの行の**折り返し位置が一致している。**
また、これらをトグルして `- [ ]` にしても折り返しが動かない。

> 未トグルの `[X]` 行だけは、描画が測定より数px 広くなるため
> 右端がわずかにはみ出すことがあります。**これは既知で、許容しています。**
> トグルすれば解消します。

### 6-d. 【本命】1行に収まるかどうかの境目

**6-b / 6-c は必ず折り返すので、実は検証になっていません。**
`- [ ]` が単独で1行を占めるため、本文の折り返しはマーク幅と無関係になるからです。

問題が起きるのは、**項目全体が1行に収まるかどうかの境目**にあるときだけです。
下は1文字ずつ長くした短い項目を、`[ ]` と `[X]` で2組並べたものです。

- [ ] あいうえおかきくけこさし
- [ ] あいうえおかきくけこさしす
- [ ] あいうえおかきくけこさしすせ
- [ ] あいうえおかきくけこさしすせそ
- [ ] あいうえおかきくけこさしすせそた
- [ ] あいうえおかきくけこさしすせそたち
- [ ] あいうえおかきくけこさしすせそたちつ
- [ ] あいうえおかきくけこさしすせそたちつて
- [ ] あいうえおかきくけこさしすせそたちつてと
- [ ] あいうえおかきくけこさしすせそたちつてとな
- [ ] あいうえおかきくけこさしすせそたちつてとなに
- [ ] あいうえおかきくけこさしすせそたちつてとなにぬ

- [X] あいうえおかきくけこさし
- [X] あいうえおかきくけこさしす
- [X] あいうえおかきくけこさしすせ
- [X] あいうえおかきくけこさしすせそ
- [X] あいうえおかきくけこさしすせそた
- [X] あいうえおかきくけこさしすせそたち
- [X] あいうえおかきくけこさしすせそたちつ
- [X] あいうえおかきくけこさしすせそたちつて
- [X] あいうえおかきくけこさしすせそたちつてと
- [X] あいうえおかきくけこさしすせそたちつてとな
- [X] あいうえおかきくけこさしすせそたちつてとなに
- [X] あいうえおかきくけこさしすせそたちつてとなにぬ

**見るのは1点だけです。**
上の組と下の組で、**「2行に折り返し始める項目の位置が同じか」。**

同じなら、`[ ]` と `[X]` が同じ幅として測られている = 修正5 が効いています。
ずれていれば効いていません。

さらに、**折り返し始める直前の項目をトグルしてみてください。**
1行のままなら成功です。2行に変わったら、その行の下のテキストが
1行分どこにも表示されなくなっている可能性があります。

## 節8: チェックボックスが無いページ

ここから先はしばらく本文だけが続きます。側面ボタンは通常のページ送りとして
動作するはずです。カーソルはどこにも表示されません。

書籍端末で文章を読むという行為は、紙の本を読むこととは少し違う体験になります。
画面の書き換えに時間がかかること、指で押す場所が決まっていること、
明かりの下でしか読めないこと。制約はいくつもあります。

それでも電子ペーパーの端末を選ぶ理由があるとすれば、
何百冊もの本を持ち歩けることと、目が疲れにくいことでしょう。
液晶画面の光を長時間見続けるのとは、疲れ方が明らかに違います。

この端末は中国の小さなメーカーが作ったもので、
出荷時のファームウェアは中国語と英語にしか対応していません。
有志が作ったカスタムファームウェアを導入することで、
表示や操作を自分の好みに合わせられるようになります。

ただし、その導入経路は個体によって異なります。
USB 経由での書き込みが工場出荷時に無効化されている個体では、
SD カードを使った書き込みだけが唯一の手段になります。

この制約は不便に見えますが、悪いことばかりでもありません。
SD カード経由の手順は、USB がロックされているかどうかに関わらず同じように使えます。
つまり、手順書を分岐させる必要がないということです。

日本語を表示するためには、日本語の字形を含むフォントが必要になります。
組み込みのフォントには漢字も仮名も入っていないため、
別途フォントを用意して SD カードに置く必要がありました。

この点も、フォントを本体に焼き込むことで解決できます。
利用者がフォントを用意しなくても、最初から日本語で使える状態になります。

さて、そろそろ本文が終わります。次の節にはチェックボックスが戻ってきます。

期待: ここまでのページで側面ボタンが通常のページ送りとして動くこと。
`>` が画面のどこにも出ないこと。

## 節10: ファイルの末尾

以下がこのファイルの最後のチェックボックスです。

- [ ] 最後の項目

ここで「次へ」(側面ボタン) を押しても、**何も起きないのが正しい挙動です。**
ファイルが閉じてホーム画面に戻ってしまったら、最終ページの例外処理が
効いていません。

なお前面ボタンでのページ送りは通常どおり動くので、
そちらを押せばこれまで通りホームに戻ります。
