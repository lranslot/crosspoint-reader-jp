### 判定の結果 (2026-10-29)

**試し刷りと並べて 5 項目を確認し、すべて一致した。**
比較画像は `docs-jp/mockups/vertical/ref_vs_proof.png` (再生成できるので追跡しない)。

| # | 項目 | 参考画像 | 試し刷り |
|---|---|---|---|
| 1 | `「` の角 | **上辺と右辺** | 一致 |
| 2 | `」` の角 | **左下** | 一致 |
| 3 | `（` の弧 | **上に膨らむ** | 一致 |
| 4 | `）` の弧 | **下に膨らむ** | 一致 |
| 5 | `ー` | **縦棒** | 一致 |

**→ `f5-vertical-writing.md` §15.7 の補正版 (`VerticalCW`) で正しい。**

### ★ 追記 (2026-10-30): この 5 項目では足りなかった

**上の 5 項目はすべて「字の形」であって、
「升目のどこに置かれているか」を見ていない。**
実機で組んだところ、形は全部正しく、
**`「` と `」` が升目の中で上下逆**だった。

参考画像から格子を復元して再測した結果 (em = 20.0 px):

| 字 | 上余白 | 下余白 | 左余白 | 右余白 | 寄る先 |
|---|---|---|---|---|---|
| `「` | 13.5 | **0.5** | 2.5 | 0.5 | **後ろの字** |
| `」` | **1.5** | 12.5 | 0.5 | 3.5 | **前の字** |
| `、` | 1.5 | 14.5 | 13.5 | 0.5 | 右上の角 |
| `。` | 2.0 | 12.0 | 13.5 | 0.5 | 右上の角 |
| `ー` | 2.5 | 2.5 | 8.5 | 8.5 | **中央** |
| `ャ` | 4.5 | 4.5 | 5.5 | 1.5 | **上下中央** |
| `ぉ` | 4.5 | 4.5 | 5.5 | 1.5 | **上下中央** |
| `ぇ` | 3.5 | 3.5 | 6.5 | 1.5 | **上下中央** |
| `ィ` | 4.5 | 2.5 | 6.5 | 4.5 | **上下中央** |

**格子の復元のしかた**: 1 列分の墨の帯を数え、
**同じ字が 2 度出てくる場所**を探して送りを求める
(`機` が 6 マス間隔 → em = 20.0 px)。全角漢字の墨が升目をほぼ埋めるので、
そこから升目の上端が決まる。

**切り出しを並べて見るだけでは決まらない —— 格子は写っていない。**
詳細は `f5-vertical-writing.md` §17、教訓は仕様書 §8.7-15。

#### 切り出しの道具

```
python scripts/png_crop.py <入力.png> --info
python scripts/png_crop.py <入力.png> <出力.png> --rect x,y,w,h --zoom 4
```

参考画像はカラー PNG で `bmp_to_png.py` が書く形式とは違うため、
最小限の復号を持つ道具を別に用意した。

## 回転方向の確認には実機の写真が要らなくなった (2026-10-28)

当初、`Rotated90CW` の向きを**側面ボタンのラベルの写真**で確かめる予定だった。
**要らなくなった。**

| # | 理由 |
|---|---|
| 1 | **ラベルは `">"` と `"<"` の 1 文字**で、読む向きが観察できない |
| 2 | **字形が組み込みフォント** (`notosans_8_regular`) にあり、リポジトリの中で測れる |
| 3 | 頂点の行き先を写像の式から計算すれば、**座標系の向きに依存せず**判定できる |

**結果は `f5-vertical-writing.md` §16.2。**

## 規格

| 資料 | 用途 | 取得 |
|---|---|---|
| **UTR #50 `VerticalOrientation.txt`** | **字ごとの縦書きの向き (U / R / Tu / Tr)。**約物の回転表の出どころ | 下記 |

```
curl -o VerticalOrientation.txt \
  https://www.unicode.org/Public/UCD/latest/ucd/VerticalOrientation.txt
python scripts/gen_vertical_orientation.py VerticalOrientation.txt --emit
```

> **⚠️ `https://www.unicode.org/Public/vertical/latest/VerticalOrientation.txt`
> は 404 になる。**UCD 側の道を使うこと。
> 指示書に書かれていた道は古い。

**元ファイルはリポジトリに含めない** (192 KB、Unicode の配布物)。
`scripts/vertical_orientation_table.py` が我々の範囲の抜粋で、
**こちらは自動生成してコミットしてある。**
