## 0. この文書について

**配布物の仕様であって、コードを触るときの前提ではない。**
だから仕様書 (v0.8) には入れず、独立させてある。

仕様書は「このコードをどう触るか」を持つ。こちらは「**使う人に何を渡すか**」を持つ。
Phase E に着手するとき、手順書を書く前にこの一覧を上から順に潰す。

> **⚠️ Phase E には Phase B (UI フォントの焼き込み) が必須である。**
> フォントを焼き込まないと「SD にフォントを置かないと日本語が出ない」という
> 制約が残り、`.bin` のみの配布が成立しない (仕様書 §5.3 / §7.4)。

## 1. 手順書に必ず含めるべき事項 (12項目)

| # | 項目 | なぜ要るか |
|---|---|---|
| 1 | **ロック判定の方法** — Chrome / Edge で xteink.dve.al を開き、ポートが出るかを見る | ロック品かどうかで案内が変わる。読者は自分の端末がどちらか知らない |
| 2 | **ロック品でも SDカード経由で書き込める**こと | ここを書かないと「USB が使えないから無理」で諦める |
| 3 | **世代を跨ぐ更新には Escape Hatch が必要**なこと | **最重要。**1.4系の SD 更新機能は 1.5系イメージを「Invalid firmware file」で拒否する。これを知らないと詰む (仕様書 §2.5) |
| 4 | **初回起動時にキャッシュ再生成で時間がかかる**こと | develop ベースのため。実測2〜3秒だが、知らないと「壊れた」と思う |
| 5 | 本文フォントの導入方法。**無くても設定画面は操作できる**こと。ただし**無いと書名・ファイル名が読めない**こと | Phase B の成果と、その限界。下の #12 と対で書く |
| **12** | **★ フォントは 8/10/12/14/16/18 の 6 サイズすべてを生成すること** | **下記** |
| 6 | **復旧用ファームの事前確保** | 書き込む前に退路を用意させる。一覧は仕様書 §2.5 |
| 7 | **SDルートに `update.bin` を常設しない**運用ルール | 誤爆防止。毎回の起動で更新が走る事故を避ける |
| 8 | **Error 9 は文鎮化ではない**こと | 既知の未解決バグ。再起動して再試行すればよい。これを書かないと「壊した」と思わせる |
| 9 | **1.2.0 系を導入しない**こと | ロック品 X4 で OTA が常に失敗する既知事例がある (RAM不足による TLS+書き込みの競合)。**更新手段を失う** |
| 10 | **コマンドはコピペ可能な形で記載** | GitHub ユーザー名の `I` と `l` の取り違え等が実際に起きる |
| 11 | **SDカードは MLC 品を推奨** | 前カードは書き込み過多で物理故障した。フォーマットも不能になる |

---

### ★ #12 が必須である理由 — 焼き込みは SD を不要にしない

**焼き込む 349 字は UI の固定文言だけである。**
ファイル名・書名・著者名・章題・SSID のような**予測できない文字は
焼き込めないので、SD のフォントが描き続ける。**

| | 何を描くか |
|---|---|
| 焼き込んだ UI フォント (8/10/12 pt) | **UI の固定文言だけ** |
| **利用者の SD フォント (6 サイズ)** | **ファイル名・書名・著者名・章題・SSID・エラー文字列** |

**1 サイズでも欠けると、そのサイズを使う画面で任意の文字が豆腐になる。**
`setupUiFallbacks()` は pt を**厳密一致**で登録するため、近いサイズには落ちない。

#### とくに 8 pt を落としやすい

**8 pt は「小さすぎて要らない」と判断されやすいが、任意の文字を描いている。**

| 箇所 | 影響 |
|---|---|
| **ステータスバーの書名** | **読書中つねに表示される** |
| **一覧の副題と右端の値** (`GUI.drawList`) | ファイル一覧・しおり・目次すべて |
| 現在のフォルダのパス | ファイル一覧 |
| ボタンヒント (2 行に降格したとき) | 日本語ラベルで発生する |

#### ★ 配布前に確認する項目: 8 pt の豆腐

**利用者が 8 pt を生成していないと、下の 6 箇所が一斉に豆腐になる。**
配布後に最も報告されやすい症状なので、手順書とサポート文面の両方で押さえる。

| # | 箇所 | 出どころ | 深刻度 |
|---|---|---|---|
| 1 | **ステータスバーの書名** | EPUB メタデータ / ファイル名 | **高。読書中つねに表示される** |
| 2 | **一覧の副題と右端の値** (`GUI.drawList`) | 画面による | **高。ファイル一覧・しおり・目次すべて** |
| 3 | 現在のフォルダのパス | ファイルシステム | 中 |
| 4 | 最近読んだ本の書名 (Lyra 3 面テーマ) | EPUB メタデータ | 中 |
| 5 | ボタンヒント (2 行に降格したとき) | 翻訳 | 中 |
| 6 | Calibre の状態文字列 | ネットワーク | 低 |

**全箇所の一覧は `a1-ui-font-subset.md` §0.6。**

> **症状から原因を当てられるようにしておく。**
> 「設定画面は日本語で読めるのに、書名とファイル一覧だけ豆腐」
> **= 8 pt 面が無い。**焼き込んだ UI フォントは 8/10/12 pt なので
> 固定文言は出るが、任意の文字は SD 側を見るため。

**→ 手順書には「6 サイズすべて」と書き、サイズを選ばせない。**
ウェブのフォントビルダー (crosspointreader.com `/fonts`) でも
ポイントサイズは利用者が選ぶので、**既定値任せにしない。**

> **劣化の出かたは綺麗である。**`resolveTextFontId()` は文字列全体に対して
> id を 1 つだけ返すので、**1 文字でも欠ければその文字列まるごとが
> フォールバックで描かれる。**書体が文字ごとに混ざることはない
> (`a1-ui-font-subset.md` §0.5)。

## 2. 配布物

1. `update.bin` (日本語UI版)
2. 導入手順書 (**日本語主体**)
3. 推奨する本文用フォントの案内

**UI フォントを焼き込むため、フォント一式の同梱は必須ではない。**本文フォントは任意。

## 3. 想定読者

- AliExpress 等でロック品 X4 を購入した日本語話者
- **日本語表示を必要とするが、ファームウェア開発の経験がない層**

**後者を想定読者に含めることが、上の11項目すべての理由である。**
「分かっている人には不要な注意」を省くと、分かっていない人が詰む。

## 4. ライセンス

MIT (上流を継承)。**動作保証を行わない旨を明記する。**

> **⚠️ 焼き込むフォントのライセンスを確認すること。**
> OFL の Modified Version には「フォーマットの変更、あるいは新しい環境への移植」が
> 含まれる。TTF → `.cpfont` の変換はこれに該当し、**ファームウェアバイナリに
> フォントデータが入るなら「再配布」である。**
>
> - ライセンス表示の同梱が必要
> - **RFN (Reserved Font Name) のあるフォントは改名が必要**
>   (UDEV Gothic は RFN あり。派生元の BIZ UDゴシック / JetBrains Mono 分の
>   著作権表示も要る)
>
> 詳細は仕様書 附録C。**Phase B でフォントを選ぶ時点で確認する。**
